# Outreach Template

Sanitized structure from [Chapter 7](../book/07-from-match-to-message.md). The goal is a draft
you *edit*, not one you *rewrite*. Peer to peer, not applicant to gatekeeper.

## Channel rules

- LinkedIn DM first to the decision-maker. One email follow-up after ~5 days if needed.
- Never lead with HR/recruiting.
- Larger companies: DM + ATS in parallel when process requires it.
- One message that counts. No "just following up" spam.
- Keep fractional and FTE tracks in separate message shapes.

| Track | Primary contact |
|-------|-----------------|
| Fractional / advisory | Founder or CEO |
| Full-time leadership | CTO, VP Eng, or named hiring manager |

## Structure

1. **Hook** — one specific, true observation about them or the company. No flattery boilerplate.
2. **Bridge** — why you, in one line. The single most relevant proof point.
3. **Ask** — low-friction, concrete. A conversation, not a job.
4. **Sign-off** — human, brief.

## Draft skeleton

```
{first_name} —

{specific observation that proves you actually looked}.

{one line on why your background maps to what they're building}.

{low-friction ask — "worth a 20-min call?" not "please consider my application"}.

— {your name}
```

## Inputs per draft

| Input | Source |
|-------|--------|
| Role id, company, title, score, tier, notes | Morning report (TOON) |
| Contact name + why this person | Short research after commit |
| Track (fractional vs FTE) | Your search shape |
| Hook material | One true observation |
| Bridge line | [`identity-narratives.md`](identity-narratives.md) |
| Open gates | Dealbreakers still unknown |

## Before send

- [ ] First name correct
- [ ] Hook is specific and true
- [ ] Bridge is one proof point, not a resume
- [ ] Track matches the contact
- [ ] Contact is the decision-maker, not HR
- [ ] Ask is a time-boxed conversation
- [ ] You would only *edit*, not rewrite

## Voice notes

- Feed the system 5–10 real messages you've written so drafts sound like you.
- For standing self-description, prefer blocks from [`identity-narratives.md`](identity-narratives.md) over inventing new bio copy.
- If a draft needs a full rewrite, the voice capture isn't done yet.
- Save sent versions back into the voice pack; repeated edits become prompt rules.
